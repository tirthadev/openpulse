# OpenPulse

OpenPulse is a framework-free PHP and MySQL application for collecting, processing, and analyzing data from public APIs.

## Goals

- Practice modern PHP 8+ and object-oriented programming.
- Implement MVC architecture without a PHP framework.
- Use Composer and PSR-4 autoloading.
- Build a secure and maintainable MySQL persistence layer.
- Integrate external APIs and validate their responses.
- Implement batch processing, scheduled tasks, and background queues.
- Measure and optimize database performance.
- Write automated tests and maintain coding standards.

## Technology Stack

- PHP 8.3+
- MySQL 8.0+
- Composer
- Bootstrap 5
- PHPUnit
- PHPStan
- Git
